# Word lists for the English auto-restore

Embedded in the engine with `include_str!` and read by `src/english.rs`.
Generated, do not edit by hand:

```sh
python3 -m venv /tmp/wf && /tmp/wf/bin/pip install wordfreq==3.1.1
/tmp/wf/bin/python crates/vnkey-engine/data/gen_wordlists.py
cargo test -p vnkey-engine corpus -- --nocapture   # re-check, see below
```

| File | Content |
|---|---|
| `en_words.txt` | `word zipf*10`: English words with zipf >= 3.0 that Telex can transform (they contain `s f r x j w z`, or a repeated `a e o d`) |
| `vi_syllables.txt` | `telex zipf*10`: every Vietnamese syllable with a diacritic, keyed by canonical Telex (`thế` -> `thees`), frequency 0 when unknown |
| `../tests/data/vi_typing.txt` | the same syllables as typing test cases, tone key last and right after its vowel |
| `../tests/data/en_heldout.txt` | English with zipf 2.5 to 3.0, NOT in `en_words.txt`, to measure the rules that work without the dictionary |
| `../tests/data/en_escape_typing.txt` | `typed<TAB>word`: each dictionary word typed the way a Telex user does today, doubling a tone key wherever a single one would compose (`tesst` for `test`). Made once with the engine at commit be221e6, before English detection, so it records existing muscle memory; not regenerated by the script |

The `corpus_*` tests in `tests/golden_typing.rs` type every one of these
words. Vietnamese and the double-key habit must come out unchanged; the
English counts are a ratchet that may only go down. Run them after
regenerating.
